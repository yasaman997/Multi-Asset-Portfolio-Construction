# Step 10 - Risk-Adjusted Scoring

Step 10 applies a zero-hard-breach eligibility gate and relative risk-adjusted candidate-set scoring. It distinguishes a provisional all-zero-breach screen from a fully certified subset with equivalent Step 7 and common-forward evidence. The score is not an external performance grade.

The standalone scorer uses a frozen candidate-input handoff assembled from upstream project results. This reproduces the declared scoring arithmetic but is not fully automated upstream lineage
